# Swasth-AI 🧠💊

Swasth-AI is an **AI-powered healthcare assistant** designed to analyze user symptoms and provide intelligent health insights using **Generative AI** and a scalable **Spring Boot backend**.

This project demonstrates the integration of **AI-driven decision-making** with real-world backend systems, focusing on clean architecture, REST API design, and healthcare-focused problem solving.

---

## 🚀 Key Features

- AI-based symptom analysis
- Disease prediction using Generative AI models
- Personalized health recommendations
- REST API–based backend architecture
- Scalable and modular system design
- Secure and structured data handling

---

## 🛠 Tech Stack

**Backend**

**AI / GenAI**
- Generative AI
- Prompt-based intelligence
- AI-driven response generation

**Database**
